# Contribuer à ANOS

Merci d'être intéressé par la contribution à ANOS ! Ce projet vise à réduire l'empreinte carbone numérique de l'IA.

## Comment contribuer

### Signaler des bugs

1. Vérifiez que le bug n'a pas déjà été signalé
2. Ouvrez une issue avec :
   - Description claire du bug
   - Étapes pour reproduire
   - Résultat attendu vs réel
   - Votre environnement (OS, version Node.js, etc.)

### Proposer des améliorations

1. Vérifiez que l'amélioration n'existe pas déjà
2. Ouvrez une issue avec :
   - Description claire de l'amélioration
   - Cas d'usage
   - Bénéfices attendus

### Soumettre du code

1. Fork le dépôt
2. Créez une branche feature : `git checkout -b feature/ma-feature`
3. Écrivez des tests pour votre code
4. Validez que les tests passent : `npm test`
5. Committez avec des messages clairs
6. Push vers votre fork
7. Ouvrez une Pull Request

## Normes de code

- Utilisez ES2020+
- Ajoutez des commentaires pour les sections complexes
- Testez votre code
- Respectez le style existant

## Domaines prioritaires

- Optimisation des algorithmes de compression
- Support de nouveaux formats (GGML, SafeTensors, etc.)
- Modèles IA pour prédiction de compression
- Documentation
- Tests de performance
- Traductions

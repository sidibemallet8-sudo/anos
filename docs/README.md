## Tutoriels

### Compression de base
1. Installer ANOS
2. Pointer vers un fichier ou dossier
3. Exécuter `anos compress`
4. Le fichier .anos est créé

### Décompression
1. Avoir un fichier .anos
2. Exécuter `anos extract archive.anos`
3. Les fichiers sont restaurés

### Vérification
1. Exécuter `anos info archive.anos`
2. Voir les statistiques de compression
3. Vérifier l'intégrité

## FAQ

### Qu'est-ce que ANOS ?
C'est un compresseur intelligent pour réduire l'empreinte carbone numérique.

### Quels types de fichiers sont supportés ?
Tous : code, documents, images, modèles IA, datasets, archives.

### Puis-je récupérer mes fichiers exactement ?
Oui, ANOS utilise des hashes pour valider l'intégrité.

### C'est gratuit ?
Oui, ANOS est open source sous licence MIT.

### Où puis-je signaler un bug ?
Sur [GitHub Issues](https://github.com/sidibemallet8-sudo/anos/issues)

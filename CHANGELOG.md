# Change Log

## [0.1.0] - 2024-01-01

### Added
- Initial release
- CLI compress/extract/info commands
- .anos archive format
- File traversal and compression
- Integrity validation
- Basic documentation

### Features
- Compress files and directories
- Extract .anos archives
- View archive information
- Automatic format detection
- SHA256 hashing for integrity

### Known Limitations
- No AI optimization yet
- No quantization or pruning
- No encryption support
- No progress reporting
